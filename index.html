WebAssembly • WebGPU • Browser Runtime

Bring GTA V to the browser, without the native desktop requirement.

Grand-V is a reverse-engineered browser project that aims to run GTA V-like gameplay in a Chromium-based environment using WebAssembly and WebGPU.

Project

Browser-native ambition

The project currently contains a native Rust launcher and related packaging assets, and it is designed around a browser-first architecture. Vercel is a practical host for the website shell, documentation, and static assets that support the project.

Runtime

WebAssembly / WebGPU foundation

This deployment model is intended to serve the web front end while preserving the native app for desktop workflows. Browser runtime support depends on the user agent, GPU support, and WebGPU availability in Chrome-based browsers.

Current status

Ready for Vercel static delivery

This repo now has a static deployment configuration that works with Vercel. The source repo itself is still primarily a native Rust project, so the browser game runtime must be produced separately before being served in a full browser experience.
